A small, tested TypeScript reference for the turn-taking part of a real-time phone agent: knowing **what the caller actually heard** when they interrupt, and not talking over them.

<Aside type="caution" title="Not for you if…">
- You want a complete voice-agent platform. Vapi, Retell, LiveKit Agents and Pipecat already ship barge-in; this is a compact implementation of the few mechanisms that are easy to get subtly wrong, not a replacement.
- You need latency or quality numbers. Nothing here has been benchmarked, and the offline fakes answer instantly.
- You need multi-tenant routing, persistence, billing, prompt assembly or telephony provisioning. None of that is included; per-call usage totals are, for you to price.
</Aside>

## What it does

| Mechanism | The problem it solves |
|---|---|
| **Mark-confirmed playback** | Sending audio is not playing audio. Every chunk is followed by a Twilio `mark`; only echoed marks count as heard. |
| **Unspoken text from TTS alignment** | Maps “confirmed N ms played” to a text prefix using per-character timings (multi-chunk, Spanish accents, NFC/NFD, emoji, word-boundary snapping). |
| **History rewrite on barge-in** | The model's next prompt shows `"We have openings Monday [interrupted]"`, not a sentence it never finished saying. |
| **Backchannel vs interruption** | “uh-huh” and “sí claro” do not cut the agent off; a real utterance does. The classifier is pluggable. |
| **Speculative turn start** | Start the LLM on Deepgram Flux `EagerEndOfTurn`; cancel on `TurnResumed` (restoring history); keep the reply if the final transcript matches. |
| **Tool fillers** | A tool call takes a second or three. A filler (“One moment.”) plays the instant the model starts the call, through the same interruptible playback path, and never lands in chat history. Skipped when the model already said its own preamble. |
| **Prompt caching** | A phone call resends the system prompt and the whole conversation every turn. The Anthropic adapter caches both by default; system blocks with a `cacheBoundary` keep per-call facts (the time) out of the cached prefix. |
| **Latency timeline and usage** | Per-call events and per-turn distributions (p50/p90) in the `CallRecord`, plus totals for input, output, cache-read and cache-write tokens and TTS characters. |
| **Config warnings** | `hooks.onWarning` flags setups that fail silently, such as a bilingual line on an English-only speech model. |
| **Twilio Media Streams transport** | `start`/`media`/`mark`/`stop` in, `media`/`mark`/`clear` out, over a structural socket type (no `ws` import in core). |

## Install

```sh
npm install @27colab/voice-engine
```

`@anthropic-ai/sdk` and `ws` are **optional peer dependencies**: install them only if you use the Anthropic adapter or run a WebSocket server.

## Bring your own keys

The engine itself needs nothing. The live provider adapters need your own accounts:

| Variable | Used by |
|---|---|
| `DEEPGRAM_API_KEY` | Deepgram Flux speech-to-text adapter |
| `ELEVENLABS_API_KEY`, a voice id | ElevenLabs text-to-speech adapter (any voice id; per-language voice selection) |
| `ANTHROPIC_API_KEY` | Anthropic Messages chat adapter |
| A Twilio number with TwiML streaming to your `wss://` URL | Transport. Twilio credentials are not read by this package. |

## API overview

**Entry points** (`@27colab/voice-engine`)

- `createCallSession(deps, info, hooks, config)` returns a session with `start()` and `end(reason)`. `deps` is `{ transport, sttFactory, ttsFactory, chat }`; `hooks.onEnd(record, reason)` receives a `CallRecord` (transcript, stats, events).
- `TwilioMediaTransport(ws)` with `await transport.started` giving `streamSid`, `callSid`, `customParameters`.
- `CallSessionConfig`: `languages`, `languagePolicy` (`'fixed'` or `'follow-caller'`), `greeting`, `system` (a string, `SystemBlock[]` with `cacheBoundary`, or a function of language and time returning either), `llm`, `tools` and `executeTool` (a tool result may set `endCall: true`), `fillers` (`{ toolName: "One moment." }` or per language), `voice`, `stt`, `maxCallSeconds`, `turnTaking` (`speculative`, `bargeInMinWords`, `classify`, `playbackPaddingMs`).
- Hooks: `onEnd(record, reason)` (`record.stats.usage` holds the token and character totals), `onError(err)`, `onWarning(message)`.

**Interfaces** (all in `interfaces.ts`): `MediaTransport`, `SttFactory`/`SttStream`, `TtsFactory`/`TtsStream`, `ChatEngine`. Implement them to swap any provider.

**Building blocks, usable on their own:** `splitAtPlayedMs`, `computeSpokenText`, `AlignmentAccumulator`, `PlaybackTracker`, `rewriteOnBargeIn`, `classifyUtterance`, `detectLang`, `CallTimeline`, `selectVoice`.

**Adapters** (`@27colab/voice-engine/providers`): `createDeepgramFluxFactory`, `createElevenLabsFactory`, `createAnthropicChat(apiKey, { cacheSystem, cacheHistory })` (both default on), and `buildAnthropicRequest` to see the exact request it sends.

**Fakes** (`@27colab/voice-engine/testing`): `FakeTransport` (`confirmPlayedMs(ms)`, Twilio-style mark echo on `clear`), `FakeStt` (`emitEagerEndOfTurn`, `emitTurnResumed`, `emitEndOfTurn`), `FakeTts` (deterministic alignment), `FakeChat` (scripted turns and tool calls, optional `gate` to simulate latency).

## Limits

- **`playedMs` is a lower bound.** It advances only at echoed marks, so resolution is the TTS chunk size. The rewrite errs toward “heard less”, never more.
- **Alignment assumptions are unverified against the live API.** Fields are read as ElevenLabs `chars` / `charStartTimesMs` / `charDurationsMs`; chunk timestamps may be chunk-relative or cumulative and a heuristic handles both. Verify against your account. Providers that rewrite text inside the alignment (such as number expansion) will mis-map.
- **Without alignment** the session falls back to a crude fixed ~15 chars/s estimate.
- **Buffer-then-speak.** Each agent turn is synthesized as one utterance; sentence-by-sentence streaming TTS is not implemented.
- **Speculation trade-off.** A speculative reply can begin speaking before the final end-of-turn; if cancelled, the caller may hear a clipped fragment. Disable with `turnTaking.speculative: false`.
- **Heuristics, not models.** The backchannel list (EN/ES) and `detectLang` are small word lists. Replace `classify` for anything serious.
- **Providers are not tested in CI.** Message shapes follow the vendors' docs at the time of writing and can drift.
- **Caching has a floor.** Each model only caches a prefix above its minimum (512 to 4,096 tokens depending on the model; 4,096 on Claude Haiku 4.5). Below it nothing is cached and `usage.llmCacheReadTokens` stays 0. History caching usually crosses the floor from the second turn.
- **Single process, in-memory.** No reconnect, no resumption, no tenancy, persistence or billing.
