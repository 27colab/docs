## What it does

- **Keyword classifier:** STOP / STOPALL / UNSUBSCRIBE / CANCEL / END / QUIT, START / UNSTOP, HELP, YES. Tolerant of case, accents, punctuation, emoji, zero-width characters and whitespace. English and Spanish built in, extensible.
- **Consent state machine** per `(accountId, phone)`: `none → pending → opted_in → opted_out`, with idempotent STOP and re-opt-in via START.
- **`guardSend()`**: a pure allow/deny decision with a reason (consent required, opt-outs honored, opt-out footer required, quiet hours in the recipient's time zone).
- **`sendGuarded()`**: guard plus provider call that never reports a “phantom send”.
- **`ConsentStore`** interface with in-memory and SQLite adapters.
- **Twilio webhook helper** (no Twilio SDK): inbound STOP/START/HELP handling, TwiML response, `X-Twilio-Signature` verification.

## API overview

| Export | Purpose |
|---|---|
| `classifyInbound(body, options?)` | `STOP`, `START`, `HELP`, `YES` or `OTHER`. Add languages via `{ stop, start, help, yes }`. |
| `applyConsentEvent(store, accountId, phone, event)` | Events: `request_opt_in`, `confirm`, `grant`, `stop`, `start`. Returns `{ record, changed }`. |
| `getConsent`, `normalizePhone` | Read a record; normalize a phone number (invalid input throws `InvalidPhoneError` on writes). |
| `handleInbound({ store, accountId, from, body, replies })` | Classify, update consent, and return the reply text to send with kind `reply`. |
| `defaultReplies(brand, helpContact?)` | Stock STOP/START/HELP replies. |
| `guardSend(record, body, options)` | Pure decision: `{ allow: true }` or `{ allow: false, reason, detail, retryAt? }`. |
| `sendGuarded({ store, accountId, phone, body, send, ... })` | Guard plus provider call; `sent: true` only if allowed **and** the provider resolved. |
| `ensureOptOutFooter`, `hasOptOutFooter` | Append or detect an opt-out instruction. |
| `isQuietHour`, `nextAllowedTime` | Quiet-hours helpers (default 21:00–08:00 recipient-local). |
| `MemoryConsentStore`, `SqliteConsentStore` | Stores. |
| `handleTwilioInbound`, `verifyTwilioSignature`, `twiml`, `parseFormBody` | Twilio webhook helpers. |

### Guard reasons

| reason | meaning |
|---|---|
| `empty_body` | nothing to send |
| `opted_out` | recipient sent STOP; only START re-enables |
| `no_consent` / `pending_confirmation` | no confirmed opt-in on record |
| `missing_opt_out_footer` | body does not tell the recipient how to opt out |
| `timezone_required` | quiet hours are on but no recipient time zone was given (fails closed) |
| `quiet_hours` | inside the quiet window; `retryAt` is the next allowed minute |
| `send_failed` | (`sendGuarded` only) the provider call threw |

Send kinds: `message` (needs `opted_in`), `opt_in_request` (allowed for `none` and `pending`, never for `opted_out`), `reply` (a direct response to an inbound message such as a STOP confirmation; always allowed, so use it only for that).

## Limits

- **STOP wins ties.** A message of up to three words containing a stop word (“please stop”, “yes stop”) is a STOP. Longer free text only counts when it *starts* with a stop word; “I can never stop thinking about it” is `OTHER`.
- **`ok` and `sure` are intentionally not YES**: too ambiguous to treat as consent.
- **Your consent collection is outside this package.** It records and enforces; it cannot tell you whether the way you obtained consent is sufficient.
- **Quiet hours are a convention, not a legal rule set.** The default window is a starting point; whether and when your messages must be restricted depends on your jurisdiction and program.
